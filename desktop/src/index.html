Settings

Running in
Page origin

The backend only accepts requests from its allowed origins: by default Tauri, localhost:1420 and localhost:5500 (change them with inventix.cors.allowed-origins). If the page origin above isn't one of them, requests fail as if the backend were down.

Backup and restore

Saves a copy of the whole database as a .zip file on the computer running the backend. It is safe to back up while the app is in use. Copy backups to another drive or cloud folder now and then.

Backups

Restoring happens the next time the backend starts: stop it and start it again. The database in use then is kept next to the restored one, so nothing is lost.
